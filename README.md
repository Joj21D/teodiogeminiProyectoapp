# Control de Ventas y Compras

Aplicación Android para registrar ventas y compras diarias, con resumen automático mensual.

## Funcionalidades

- **Registro diario**: agrega compras y ventas en cualquier fecha, con el resultado neto del día calculado automáticamente.
- **Importar / Exportar**: permite importar y exportar los datos (incluye exportación a Excel).
- **Edición de registros**: cada entrada puede editarse desde el detalle; los cambios se marcan en amarillo para identificar rápidamente qué se modificó.
- **Selector de fecha**: navega y filtra los registros por fecha.
- **Resumen General**: muestra, por mes, el número total de ventas y compras, la compra más grande, la venta más grande, y el neto acumulado del mes.

## Tecnologías

- Java
- Android SDK
- Gradle (Kotlin DSL)

## Cómo usar

1. Abre la tabla de datos (calculadora) para ver los registros del día.
2. Usa ➕ para agregar una nueva compra o venta.
3. Usa 📥 / 💾 para importar o exportar tus datos.
4. Usa 📅 para cambiar la fecha y ver otros días.
5. Presiona **"Detalle"** en cualquier registro para ver más información o editarlo.
6. Revisa **Resumen General** para ver las estadísticas acumuladas del mes.
